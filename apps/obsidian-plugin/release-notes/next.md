# Next Obsidian plugin release

## Added

- A conflict view (command: "Open conflict view") listing the conflict copies sync left in your vault. Each entry shows the file it belongs to, when the copy was made, and the size of both versions; select the name to open the file.
- Resolve a conflict from a comparison of the two versions (a line-by-line diff for text, side by side for images) by keeping the original or keeping the copy. When the copy only adds lines to the original, it can be merged in one step from the list. Resolved copies are removed according to your trash settings.
